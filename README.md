# sfe
Solving Flutter Equations with Numerical Continuation

This repository is for an open source book I am
working on titled "Solving Flutter Equations",
possibly subtitled "Using numerical continuation
and automatic differentiation".
The goal in writing this book is to give flutter
engineers a much more powerful method for analyzing
aircraft for flutter instabilities than traditional
eigenvalue-based methods. An implementation of
the theory presented will be available as
open source.

The ideas presented in this book began in 1975
with a program I wrote for my PhD thesis, contributed
to the Boeing Company during my 32 years there, and
continued in retirement with several papers.
